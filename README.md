# Phuket Families

Next.js/TypeScript site for phuketfamilies.com, the Phuket sister site of
BKK Families (bkkfamilies.com). Started as a copy of the bkkfamilies codebase.

## Stack
- Next.js (App Router) + TypeScript
- Tailwind CSS
- No database: content lives in `src/lib/schools.ts` and `src/lib/articles.ts`

## Commands
- `npm run dev` for local development
- `npm run build` to check a production build
- `bash scripts/linkcheck.sh` to check school website links
